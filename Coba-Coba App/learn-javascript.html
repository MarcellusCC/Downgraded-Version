JavaScript Essentials

Variables, functions, arrays/objects, DOM, events, async.

1 What is JavaScript?

The language of the web—adds logic and interactivity to HTML/CSS.

console.log("Hello from JavaScript!");

2 Variables & Types

Use let/const. Primitive types: string, number, boolean, null, undefined, symbol, bigint; and objects.

const site = "WebVantage"; let visitors = 100n; // bigint const user = { name:"Ava", paid:false };

3 Operators & Equality

Prefer strict equality ===/!== to avoid coercion surprises.

2 === "2" // false 2 == "2" // true (coerces) +"5" + 1 // "51" (string concat)

4 Control Flow: if/else & Switch

Branch logic using conditions or switch statements.

const score = 87; let grade = score >= 90 ? "A" : "B"; switch(grade){ case "A": console.log("Great!"); break; default: console.log("Keep going!"); }

5 Loops & Iteration

for, while, for...of for iterables; for...in for object keys.

const arr=[1,2,3]; for(const n of arr){ console.log(n*n); }

6 Functions (Arrow & Params)

Functions encapsulate reusable logic; default & rest params simplify signatures.

const greet = (name="friend") => `Hi, ${name}!`; const sum = (...nums) => nums.reduce((a,b)=>a+b,0);

7 Scope, Hoisting & TDZ

let/const are block-scoped and live in a temporal dead zone until declaration.

// console.log(x); // ReferenceError (TDZ) let x = 3; function f(){ y = 10; } // implicitly creates global in sloppy mode (avoid!)

8 Arrays

Common methods: push, slice, map, filter, reduce.

const prices=[10,15,20]; const withTax = prices.map(p=>p*1.1); const total = withTax.reduce((a,b)=>a+b,0);

9 Objects & Destructuring

Key–value structures; destructure for cleaner code.

const user={name:'Ava',plan:'Pro'}; const {name, plan} = user; const clone = { ...user, active:true };

10 JSON & Storage

Serialize with JSON and persist small state in localStorage.

const prefs = { theme:'dark', volume:0.7 }; localStorage.setItem('prefs', JSON.stringify(prefs)); const restored = JSON.parse(localStorage.getItem('prefs')||'{}');

11 DOM Selection & Traversal

Use querySelector, closest, and node properties.

const el = document.querySelector('#demo-js-11'); el.textContent = 'Updated!';

12 DOM Manipulation & Templates

Create elements, set attributes, and insert efficiently.

const li=document.createElement('li'); li.textContent='New item'; document.querySelector('#list-js-12').append(li);

    13 Events

    Listen with addEventListener; use delegation for dynamic lists.

    document.addEventListener('click', e=>{ if(e.target.matches('.js-like')) e.target.textContent='❤️'; });

    14 Forms & Validation

    Intercept submits; validate with constraints or custom rules.

    form.addEventListener('submit', e=>{ e.preventDefault(); if(!email.checkValidity()) return alert('Invalid email'); alert('Submitted!'); });

    15 Fetch API & Async/Await

    Work with promises; await makes async flow readable.

    // Example (would need a real endpoint): async function getData(){ const res = await fetch('/api/example.json'); return await res.json(); }
    Tip: In your real app, handle network errors with try...catch.

    16 Promises & Error Handling

    Chain with .then()/.catch(), or use try...catch with await.

    new Promise(res=>setTimeout(()=>res(42),300)) .then(v=>v*2) .catch(err=>console.error(err));

    17 Modules (ESM)

    Split code into files with export/import (requires bundler or module-aware server locally).

    // math.js export const add=(a,b)=>a+b; // main.js import { add } from './math.js';

    18 Prototypes & Classes

    Classes wrap prototype chains with clean syntax.

    class Counter{ #n=0; inc(){ this.#n++; } get value(){ return this.#n; } } const c=new Counter(); c.inc();

    19 this, Bind & Call

    this depends on call-site; arrow functions capture lexical this.

    const obj={x:7, getX(){return this.x;}}; const unbound = obj.getX; const bound = unbound.bind(obj); bound(); // 7

    20 Performance & Best Practices

    Avoid layout thrash; debounce expensive handlers; prefer immutable patterns and pure functions.

    // Debounce: const debounce=(fn,ms=200)=>{let t;return (...a)=>{clearTimeout(t);t=setTimeout(()=>fn(...a),ms)}}; // Usage: window.addEventListener('resize', debounce(()=>console.log('resized')));
