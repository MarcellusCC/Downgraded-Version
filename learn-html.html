HTML Fundamentals

Learn the building blocks of the web (elements, attributes, structure, forms, tables).

1 What is HTML?

HTML defines the structure of web pages using elements and tags.

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>My First Page</title> </head> <body> <h1>Hello, World!</h1> </body> </html>

Hello, World!

This is how the HTML above renders in a browser.

2 HTML Document Structure

A valid document includes <!DOCTYPE>, <html>, <head>, and <body>.

<html lang="en"> <head> ... metadata ... </head> <body> ... visible content ... </body> </html>

3 Common Tags

Headings, paragraphs, links, and images are used constantly.

<h1>Main Heading</h1> <p>Paragraph text.</p> <a href="https://example.com">A link</a> <img src="photo.jpg" alt="Description" width="300">

Preview

🔗 This is a link

Tip: Always include alt text for images.

4 Lists

Use <ul>/<ol> with <li> for items; definition lists with <dl>.

<ul> <li>First</li> <li>Second</li> </ul> <ol> <li>Step one</li> <li>Step two</li> </ol> <dl> <dt>Term</dt> <dd>Explanation</dd> </dl>

5 Forms (Basics)

Forms collect user input via inputs, selects, textareas, etc.

<form action="/submit" method="post"> <label for="email">Email</label> <input id="email" name="email" type="email" required> <button type="submit">Send</button> </form>

6 Semantic HTML (HTML5)

Use meaning-rich tags for structure and accessibility.

<header>...brand...</header> <nav>...links...</nav> <main> <article> <h1>Title</h1> <section>Content</section> </article> <aside>Related</aside> </main> <footer>©</footer>

7 Head & Metadata

Character set, viewport, title, description, favicon, and social previews.

<meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>Page Title</title> <link rel="icon" href="/favicon.ico"> <meta name="description" content="Short summary."> <meta property="og:title" content="Social Title">

8 Links & Navigation

Absolute vs relative URLs, in-page anchors, download links, and target behavior.

<a href="/about.html">Internal</a> <a href="https://example.com" rel="noopener" target="_blank">External</a> <a href="#faq">Jump to FAQ</a>

9 Images & Figures

Alt text, captions with <figure>/<figcaption>, responsive images.

<figure> <img src="cat.jpg" alt="A black cat sleeping"> <figcaption>Midnight, the cat.</figcaption> </figure> <img src="small.jpg" srcset="small.jpg 480w, medium.jpg 800w, large.jpg 1200w" sizes="(max-width:600px) 90vw, 600px" alt="Responsive">

10 Tables (with Accessibility)

Use headers, scope, captions; avoid tables for layout.

<table> <caption>Monthly Sales</caption> <thead><tr><th scope="col">Month</th><th scope="col">Sales</th></tr></thead> <tbody><tr><th scope="row">Jan</th><td>$10k</td></tr></tbody> </table>

11 Forms (Input Types & Validation)

Modern input types, constraints, native validation, labels.

<input type="number" min="0" max="10" required> <input type="date"> <input type="file" accept="image/*"> <input type="text" pattern="\\d{3}-\\d{3}" title="123-456">

12 Accessibility Essentials

Meaningful alt text, labels, headings, and ARIA only when needed.

<button aria-label="Open navigation"> <svg aria-hidden="true">...</svg> </button> <img src="chart.png" alt="Bar chart of Q1–Q4 revenue">

13 Media: Audio & Video

Native players, controls, captions/subtitles via <track>.

<video controls width="360"> <source src="intro.mp4" type="video/mp4"> <track kind="captions" src="intro.vtt" srclang="en" label="English"> </video> <audio controls src="beat.mp3"></audio>

14 Embeds & Iframes

Sandboxing, responsive sizing, and loading hints.

<iframe src="https://example.com" loading="lazy" referrerpolicy="no-referrer" sandbox="allow-scripts allow-same-origin" width="560" height="315"></iframe>

15 Text-Level Semantics

Emphasis vs strong, code, kbd, sup/sub, quotes, time, and entities.

<p>Press <kbd>Ctrl</kbd>+<kbd>S</kbd> to save.</p> <code>console.log('hi')</code> &copy; &mdash; &amp;

16 Performance Hints (HTML-side)

Preload key assets, defer scripts, lazy-load media/images.

<link rel="preload" as="font" href="/inter.woff2" crossorigin> <script src="/app.js" defer></script> <img src="hero.jpg" loading="lazy" alt="Hero">

17 SEO Basics

Use a single <h1>, descriptive titles, meta description, and sensible headings.

<title>HTML Forms: Complete Guide</title> <meta name="description" content="Learn input types, labels, and validation."> <h1>HTML Forms</h1> <h2>Input Types</h2>

18 Data on the Page: Microdata & JSON-LD

Provide machine-readable context (e.g., articles, products) for search engines.

<script type="application/ld+json">{ "@context":"https://schema.org", "@type":"Article", "headline":"HTML Fundamentals", "author":{"@type":"Person","name":"WebVantage"} }</script>

19 Graphics: SVG & Canvas (Intro)

Inline SVG for icons; canvas for dynamic drawing (JS-driven).

<svg width="48" height="48" viewBox="0 0 24 24" aria-hidden="true"> <circle cx="12" cy="12" r="10" fill="currentColor"/> </svg> <canvas id="c" width="100" height="40"></canvas> <!-- draw via JS -->

20 Best Practices & Common Pitfalls

Valid markup, no duplicate IDs, progressive enhancement, and graceful fallback.

<!-- ✅ Good: unique IDs, proper nesting, alt text --> <main id="content">...</main> <!-- ❌ Bad: duplicate IDs, missing alt, mis-nested tags --> <div id="x">...</div> <div id="x">...</div> <!-- duplicate -->
